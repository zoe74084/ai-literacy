## 在本機查看網站

需要 Node.js 24。在專案資料夾執行：

```bash
npm install
```

```bash
npm run dev
```

然後開啟 http://localhost:4321/ai-literacy/ 。原文勘誤頁在 http://localhost:4321/ai-literacy/read/errata/ 。

## 修改紀錄放在哪裡

- `src/data/errata.json`：甲類（原文錯字）的修正，網站〈原文勘誤〉頁會列出
- `src/data/fixes.json`：乙類（轉檔問題）的修正
- 教育部回覆後，把修正內容加進這兩個檔案，重新執行 `npm run build` 即可套用
