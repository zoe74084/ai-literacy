# 教育部教育大數據介接合作協議書

中華民國 115 年 8 月 21 日臺教資 ( 三 ) 字第 1152701240 號核定

教育部 ( 以下簡稱甲方 ) 為進行數位學習平臺 / 系統資料介接、匯集我國教育大數據，提供分析成果， <u>(</u> 以下簡稱乙方 ) 之 <u>(</u> 數位學習平臺 / 系統名稱 ) 同意雙方透過應用程式介面 (Application Programming Interface, API) 之方式進行資料介接，雙方簽訂教育大數據介接合作協議書 ( 以下簡稱本協議書 ) ，以玆遵循：

## 壹、通則

- 一、目的：教育部為辦理 AI 人才方舟計畫（以下簡稱方舟計畫）推動數位學習、提升中小學學生 AI 素養，並強化中小學教師運用 AI 融入教學之能力，由方舟計畫之子計畫三「教育大數據分析計畫」建置、維運教育大數據資料倉儲系統，與公私數位學習平臺 / 系統 ( 以下簡稱平臺 / 系統 ) 協力合作，整合平臺 / 系統使用者之學習歷程資料，運用人工智慧分析技術及學習分析技術，作為教育政策制定與教育治理、學校教學支持及學生個人化學習之之應用基礎，以提供適性學習環境並促進公平優質教育之發展；並推動個資加密與去識別化之離線存取資料釋出，促進縣市數據運用及發展資料素養增能，以提升教育人員之資料識讀與應用能力，特由雙方辦理資料介接合作。

- 二、資料利用範圍：乙方提供之資料，供甲方於符合個人資料保護法、資通安全管理法及相關法令規定下，使用於教育部推動數位學習、教育大數據分析及相關應用業務，包括但不限於教育大數據儀表板、縣市數據應用、資料素養培訓，以及經去識別化之教育大數據開放資料等用途。

- 三、資料安全與保護：

   - ( 一 ) 雙方同意依著作權法、個人資料保護法、資通安全管理法或相關法令與本協議書規定，授權、管理平臺 / 系統服務資訊與學習資料。

   - ( 二 ) 乙方應向使用者揭露與雙方之合作意旨及範圍，但不得單純以任一方名義為之，並應提供完整之資訊予使用者，且不得有虛偽、詐欺、隱匿或其他足致他人誤信之情事。

   - ( 三 ) 雙方應落實資訊安全防護相關作業，傳輸過程一律加密，防止非法入侵、取得、竄改或毀損本介接作業所取得之資料，不得從事駭客攻擊、病毒植入、惡意程式或其他任何不法行為。

   - ( 四 ) 雙方應避免第三人可能利用任一連結之相關渠道進行上開不法行為致雙方受有侵害之虞。

   - ( 五 ) 如發生資訊系統異常、資訊安全事件，有損使用者權益之虞時，發現方應於上開事項發生時立即通知相關人員，並採取應變處理作業。

   - ( 六 ) 如涉及本資料介接相關系統之重要變更，應於 14 日前通知對方，但因緊急情況而有立即採取必要安全措施者，應即時通知對方。

## 貳、甲方之權利義務

      - 甲方同意授予乙方得不限地域、時間或次數，透過電腦、行動載具等電子通訊設備，以合法、安全形式瀏覽教育大數據儀表板提供的統計分析報表。

- 參、乙方之權利義務

   - 一、乙方同意授予甲方及甲方委託之公務、非公務機關得不限地域、時間或次數，以電子檔、雲端資料庫等合法、安全形式，進行平臺 / 系統服務資訊與學習資料的傳遞、收錄、引用或重製，並運用於國家政策分析、學術研究或其他正當目的之重製及利用。

   - 二、資料授權範圍：依乙方函附教育大數據介接申請書附件內容所載。

   - 三、傳輸方式：以 API 將資料傳輸於甲方指定之平臺。

   - 四、介接期程：乙方應於簽訂本協議書後 3 個月內，完成 API 開發、測驗與驗證，並正式與甲方指定之教育大數據資料庫完成數據傳輸介接。倘因執行介接相關作業確有延長期限之必要，乙方應於原約定完成日前至少 1 個月，檢具書面申請文件函送甲方，並經雙方召開協商會議後，重新議定並書面確認展延後之完成期限。

   - 五、逾期責任：

      - ( 一 ) 乙方未依參、四約定期限內完成介接，且未於期限前依規定提出展延申請，或展延申請未經甲方同意者，構成違反本協議書之情形。

      - ( 二 ) 乙方有前款違約情形者，甲方得視違約情節，停止或暫緩相關合作事項之辦理，並得作為乙方未來參與甲方主辦、委辦或補助之相關計畫、產品徵件、評選、試辦、推廣及平臺 / 系統上架等資格審查之參考。

      - ( 三 ) 如乙方已獲甲方就本協議書項下之資料介接作業核定或撥付相關補助經費，且有第一款違約情形者，甲方得以書面通知乙方返還已撥付之全部或一部補助經費；乙方應於通知送達之次日起 30 日內返還完畢。乙方逾期未返還者，甲方得依法追償，並保留依法追究其所致損害之權利。

- 肆、其他事項

   - 一、雙方及其受僱人、代理人、受任人、承攬人、使用人及履行輔助人等，因執行本協議書，而自他方所取得或知悉之資料、訊息、技術、商業秘密等，除下列原因外，於執行期間及終止後，均須負保密義務：

      - ( 一 ) 經提供方事前書面同意。

      - ( 二 ) 提供方自行使該機密資訊成為公開或眾所周知之文件或資料。

      - ( 三 ) 接受方非利用機密資訊所獨自開發之資料。

   - 二、任一方違反本協議書致他方或第三人受有損害者，應自負損害賠償責任。

   - 三、本協議書內容或規定之解釋及適用悉依中華民國法律及相關規定辦理，除另有法令規定或特約外，以本協議書為準。

   - 四、雙方簽訂本協議書一式 2 份，各執 1 份為憑。
