# 教育部教育大數據介接申請規範

中華民國 115 年 8 月 21 日臺教資 ( 三 ) 字第 1152701240 號核定

## 壹、目的

教育部為辦理 AI 人才方舟計畫（以下簡稱方舟計畫）推動數位學習、提升中小學學生 AI 素養，並強化中小學教師運用 AI 融入教學之能力，由方舟計畫之子計畫三「教育大數據分析計畫」建置、維運教育大數據資料倉儲系統，持續與公私數位學習平臺 / 系統 ( 以下簡稱平臺 / 系統 ) 協力合作，導入平臺 / 系統使用者之學習歷程資料，並運用人工智慧分析技術及學習分析技術，提升資料探勘與解讀效率，作為教育政策制定與教育治理、學校教學支持及學生個人化學習之依據，提供適性學習環境及促進公平優質教育；並推動個資加密與去識別化之離線存取資料釋出，促進縣市數據運用及發展資料素養增能，以提升教育人員之資料識讀與應用能力，特訂定本申請規範。

- 貳、適用對象：已完成介接教育體系身分認證服務，並申請介接教育大數據資料之平臺 / 系統所屬單位。

## 參、辦理單位

主辦單位：教育部

承辦單位：子計畫三教育大數據分析計畫 - 教育大數據推動中心 ( 以下簡稱教育大數據推動中心 )

## 肆、介接流程

- 一、平臺 / 系統所屬單位填寫教育部教育大數據介接申請書 ( 包括使用者學習紀錄項目表及介接平臺基本資料表 ) 及提供樣本數據，並寄送予教育大數據推動中心。

- 二、教育大數據推動中心審核學習紀錄項目表內容，提供資料收錄建議。

- 三、教育大數據推動中心召開介接交流會議，說明介接流程、資料收錄建議以及資料交換共通性應用程式介面 (API) 開發注意事項，並與平臺 / 系統所屬單位議定 API 開發專案期程。

- 四、平臺 / 系統所屬單位依據介接交流會議討論建議，修訂介接申請書及相關表件，再次提交予教育大數據推動中心確認後，由平臺 / 系統所屬單位將申請書及相關表件函送教育部資訊及科技教育司。

- 五、教育部資訊及科技教育司提供 API 規格書予平臺 / 系統。

- 六、選用流程：申請介接平臺 / 系統所屬單位為直轄市、縣 ( 市 ) 政府、民間企業時，應與教育部簽署合作協議書。

- 七、經 API 開發專案之測試與驗證，完成 API 開發並將平臺 / 系統資料正式介接教育大數據資料庫。
